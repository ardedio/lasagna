# 미리보기용 자리표시자

여기 있는 JPG 는 **클라이언트 작업물이 아니다.** 실제 키비주얼이 아직 없어서
단일 파일 미리보기(`tools/build-preview.py`)에서 Work 섹션의 **크롭·비율·리듬**만
확인하려고 만든 중립 이미지다.

- 960×540 (16:9), 프로그램으로 생성한 그라데이션 + 필름 그레인
- 사이트가 그 위에 `saturate(0.25) brightness(0.86)` 를 한 번 더 건다
- 실제 KV 가 `site/assets/kv/` 에 들어오면 이 폴더는 지운다

실제 사이트(`site/`)는 이 파일을 참조하지 않는다. 미리보기 빌드 전용이다.
