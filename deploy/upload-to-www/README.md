# upload-to-www/

여기 있는 파일은 **현재 운영 중인 사이트**(`lasagna.kr`)에 올리는 것이다.
새로 만드는 프로토타입(`site/`)과는 별개다.

## index.html

현재 서버의 `/www/index.html` 에 **HTTPS 전환 스크립트만** 넣은 버전이다.

- 원본 대비 **`<head>` 바로 뒤에 `<script>` 블록 하나 추가**가 전부다.
- 디자인·문구·레이아웃은 **한 글자도 건드리지 않았다.**

### 올리는 법

1. 파일질라 — **오른쪽**은 `/www`, **왼쪽**은 `/Users/lasagna/Downloads`
2. 올리기 전에 **기존 `index.html` 을 Mac 으로 한 번 더 내려받아 백업**
3. 이 `index.html` 을 오른쪽으로 드래그 → **덮어쓰기** 선택
4. **시크릿 창**에서 `http://www.lasagna.kr` 을 열어 자물쇠 확인

> `curl -sI http://www.lasagna.kr/` 는 **여전히 `200 OK`** 가 나온다. 정상이다.
> 서버가 아니라 브라우저에서 전환하는 방식이라 그렇다.

### 되돌리기

백업해 둔 원래 `index.html` 을 다시 올리면 즉시 원상복구된다.

### 나중에 지울 것

카페24가 서버에 301 리다이렉트를 걸어주면 이 `<script>` 블록은 필요 없어진다.
그때 지우는 게 좋다 — 서버 리다이렉트가 더 빠르고 검색엔진에도 제대로 인식된다.
