# 카페24 HTTPS 적용 — 단계별 가이드

웹 처음이어도 따라 할 수 있게 썼다. **순서가 중요하다.** 건너뛰지 마라.

전체 흐름은 3단계다:

```
1단계  카페24에서 SSL 인증서 신청       (웹사이트 관리자 페이지 · 파일질라 아님)
2단계  발급됐는지 확인                  (주소창에 자물쇠 뜨는지)
3단계  http 주소를 https 로 자동 전환   (파일질라로 파일 하나 업로드)
```

> **왜 순서가 중요한가:** 3단계를 먼저 하면 "https 로 가라"고 했는데
> 정작 https 가 준비 안 된 상태라 **사이트가 안 열린다.**
> 반드시 1 → 2 → 3 순서로.

---

## 0단계 — 시작 전에 백업 (5분, 꼭 하자)

혹시 서버에 이미 설정 파일이 있으면 덮어쓰면 안 된다. 먼저 확인한다.

1. **파일질라를 켜고 사이트에 접속**한다.
2. 오른쪽(서버 쪽) 창에서 웹 폴더로 들어간다.
   카페24는 보통 **`/www`** 폴더다. (`public_html` 인 경우도 있다)
3. **숨김 파일을 보이게 설정한다** — 이게 핵심이다.
   `.htaccess` 는 이름이 점(.)으로 시작해서 **파일질라가 기본적으로 숨긴다.**

   > 파일질라 상단 메뉴 → **서버(Server)** → **숨김 파일 강제 표시**
   > (영문판: Server → Force showing hidden files)

4. 이제 `.htaccess` 파일이 보이는지 확인한다.
   - **있다면** → 그 파일을 내 컴퓨터로 **드래그해서 내려받아 보관한다.**
     (나중에 문제 생기면 이걸 다시 올려서 되돌린다)
     그리고 그 내용을 나에게 알려달라 — 기존 설정과 충치지 않게 합쳐줘야 한다.
   - **없다면** → 그냥 진행하면 된다. 백업할 게 없는 것뿐이다.

---

## 1단계 — 카페24에서 무료 SSL 신청

**파일질라가 아니라 카페24 홈페이지에서 하는 작업이다.**

1. [cafe24.com](https://www.cafe24.com) 로그인
2. 우측 상단 **나의서비스관리** (또는 **MY서비스**) 클릭
3. **웹호스팅** → 내 서비스 목록에서 `lasagna.kr` 이 붙은 서비스 클릭
4. 왼쪽 메뉴에서 **보안서버(SSL)** 또는 **SSL 인증서** 를 찾는다
5. **무료 SSL 인증서 신청** (Let's Encrypt) 선택 → 신청

### 신청할 때 주의할 것

**도메인을 두 개 다 넣어야 한다:**

```
lasagna.kr
www.lasagna.kr
```

하나만 넣으면 다른 하나로 접속했을 때 **경고가 그대로 뜬다.**
입력칸이 하나뿐이면 `www.lasagna.kr` 을 넣고, 나머지 하나도 추가 가능한지
찾아본다. 안 보이면 카페24 고객센터에 "두 도메인 모두 인증서에 포함해달라"고
문의하면 된다.

> **메뉴 이름이 위와 다르게 보이면 알려달라.** 카페24가 화면을 종종 바꾸는데,
> 화면 캡처를 보내주면 어디를 눌러야 하는지 짚어주겠다.

### 기다리는 시간

무료 SSL 은 신청 후 **몇 시간 ~ 하루** 정도 걸린다. 바로 안 된다고
잘못된 게 아니다. 카페24에서 완료 안내가 오면 2단계로 간다.

---

## 2단계 — 발급됐는지 확인

브라우저 주소창에 **`https://`** 를 직접 붙여서 들어가 본다:

```
https://www.lasagna.kr
```

- **자물쇠가 보이고 사이트가 정상적으로 뜬다** → 성공. 3단계로.
- **경고가 뜬다 / 안 열린다** → 아직 발급 전이다. 더 기다린다.

`https://lasagna.kr` (www 없이) 도 똑같이 해본다. **둘 다 자물쇠가 떠야**
다음 단계로 넘어간다. 하나만 되면 1단계의 도메인 추가를 다시 확인한다.

---

## 3단계 — http 주소를 https 로 자동 전환

2단계까지 되면 https 로는 잘 열린다. 그런데 **누가 `http://` 로 들어오면
여전히 "안전하지 않음" 이 뜬다.** 옛날 주소는 그대로 살아있기 때문이다.
그래서 "http 로 오면 https 로 자동으로 보내주는" 설정을 넣는다.

### 3-1. 파일 준비

이 저장소의 **`deploy/htaccess-for-cafe24.txt`** 파일을 내 컴퓨터로 받는다.

### 3-2. 파일질라로 업로드

1. 파일질라로 서버 접속
2. 오른쪽(서버) 창에서 **`/www`** 폴더로 이동 (0단계에서 확인한 그 폴더)
3. 왼쪽(내 컴퓨터) 창에서 `htaccess-for-cafe24.txt` 를 찾는다
4. 그 파일을 **오른쪽으로 드래그**해서 업로드
5. 업로드된 파일에 **우클릭 → 이름 바꾸기**
6. 이름을 정확히 이렇게 바꾼다:

   ```
   .htaccess
   ```

   **앞에 점(.)이 있고, `.txt` 는 지운다.** 이름은 이게 전부다.

7. 이름을 바꾸면 파일이 목록에서 사라진 것처럼 보일 수 있다 —
   숨김 파일이 되어서 그렇다. 0단계에서 **숨김 파일 강제 표시**를 켜뒀으면
   계속 보인다.

### 3-3. 테스트

브라우저 주소창에 **`http://`** 를 붙여서 (https 아님, http 임) 들어가 본다:

```
http://www.lasagna.kr
```

- **자동으로 `https://` 로 바뀌고 자물쇠가 뜬다** → 완료. 3-4로.
- **"리디렉션이 너무 많습니다" 오류** → 파일질라로 `.htaccess` 를 **지운다.**
  즉시 원래대로 돌아온다. 그리고 나에게 알려달라 — 카페24 서버 구성에 맞게
  고쳐주겠다.
- **아무 변화 없다** → 카페24가 `.htaccess` 를 안 쓰는 구성일 수 있다.
  이것도 알려달라.

### 3-4. 임시 → 영구로 바꾸기

테스트가 잘 되면 마지막 한 걸음이 남았다.

`htaccess-for-cafe24.txt` 를 메모장으로 열어서 **`R=302`** 를 찾아
**`R=301`** 로 바꾸고 저장 → 다시 업로드 → `.htaccess` 로 이름 변경.

> **왜 처음부터 301 을 안 쓰나:**
> 301 은 "영구 이동" 이라 **브라우저가 기억해버린다.** 설정이 틀렸을 때
> 파일을 지워도 한동안 계속 튕긴다. 302 는 기억하지 않아서 언제든
> 되돌릴 수 있다. 그래서 302 로 확인하고 → 301 로 굳힌다.

## 다 끝난 뒤 확인 목록

| 주소 | 기대 결과 |
|---|---|
| `http://lasagna.kr` | https 로 전환 + 자물쇠 |
| `http://www.lasagna.kr` | https 로 전환 + 자물쇠 |
| `https://lasagna.kr` | 자물쇠 |
| `https://www.lasagna.kr` | 자물쇠 |

**네 개 모두** 자물쇠가 떠야 완료다.

자물쇠 대신 **느낌표나 경고 삼각형**이 뜬다면, 페이지 안에 아직 `http://` 로
불러오는 이미지나 영상이 남아있다는 뜻이다 (혼합 콘텐츠).
`F12` → **콘솔** 탭에 `Mixed Content` 라고 뜬 줄을 복사해서 보내주면 잡아주겠다.

## 참고 — 파일질라 자체의 보안

지금 보안 얘기를 하는 김에 하나 더. 파일질라로 접속할 때 **`FTP`** 를 쓰고
있다면, **아이디와 비밀번호가 암호화 없이 그대로 전송된다.**

파일질라 → **사이트 관리자** → 해당 사이트 → **암호화** 항목을
**"명시적 FTP over TLS 필요"** 로 바꾸면 암호화된다. 카페24는 이걸 지원한다.

접속이 안 되면 원래 설정으로 되돌리고 카페24 고객센터에
"FTPS 접속 가능한지" 문의하면 된다. 급한 건 아니지만 해두면 좋다.
