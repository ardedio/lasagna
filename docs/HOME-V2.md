# Home 프로토타입 v2 — 설계 노트

## 0. 먼저 — 읽지 못한 것

이 브랜치를 시작한 시점에 `ardedio/lasagna` 저장소는 **커밋 0개, 레퍼런스 0개**였다.
`CLAUDE.md` 도 `docs/PLAN.md` 도 존재하지 않는다.

따라서 **기획 §10 미결 5개에 대한 판단은 이 문서에 없다.** 항목이 무엇인지 알 수 없고,
추측해서 채우는 것은 판단이 아니라 창작이다. PLAN.md 를 이 브랜치에 커밋하거나 §10 본문을
붙여주면 그 자리에서 5개 각각에 대해 답한다.

아래 v2 는 §10 의 답을 **선점하지 않는 범위**에서 만들었다 — 구조는 확정하되,
미결 사항이 걸릴 지점은 전부 교체 가능한 슬롯으로 남겼다.

## 1. 브랜드 하드 룰 적용

| 룰 | 적용 |
|---|---|
| 블랙 | `--ink: #0A0A0A` — 순검정(#000)이 아니라 한 단계 올린 값. 순검정은 OLED에서 경계가 죽고 하드웨어별 편차가 크다. |
| `#F15A24` | `--flame` — **유일한 액센트**. 넓은 면적에 깔지 않는다. 인덱스 번호, 호버 시 이름, 마커 사각형, 스텝 라벨. 면으로 쓰는 곳은 `.tool:hover` 하나뿐. |
| 올고딕 | Latin `Helvetica Neue` → Hangul `Apple SD Gothic Neo`. Helvetica Neue 에 한글 글리프가 없어 자동으로 폴백된다 — Mac 네이티브 올고딕 조합이 그대로 나온다. **세리프 0개.** |

> 운영 매뉴얼 §4-1 의 `Georgia + Apple SD Gothic Neo` 는 **Keynote/Numbers 산출물 룰**이다.
> 이번 지시의 "올고딕"이 웹에서는 상위 룰이라 판단해 Georgia 를 넣지 않았다. 이견 있으면 되돌린다.

웹폰트를 쓰지 않는다 — CDN 의존이 없고, 디렉터 Mac 에서 보는 화면과 배포 화면이 같다.
Pretendard 를 붙이려면 `--font` 한 줄만 고치면 된다.

## 2. 구조 판단

히어로 → 티커 → 01 Studio → 02 Work → 03 Process → 04 Stack → Contact.

**Work 를 Process 앞에 둔 이유:** 이 스튜디오의 차별점은 "AI를 쓴다"가 아니라
"AI로 이만큼 만들었다"다. 2026년에 AI 워크플로우 자체는 더 이상 셀링 포인트가 아니다.
증거를 먼저 보여주고, 그다음에 그것이 우연이 아니라 시스템이라는 걸 Process 로 증명한다.
순서를 뒤집으면 툴 자랑하는 스튜디오가 된다.

**Work 를 그리드가 아니라 인덱스 리스트로:** 7개 프로젝트를 썸네일 그리드로 깔면
유튜브 채널처럼 보인다. 에디토리얼 인덱스(번호 · 이름 · 한 줄 · 태그)로 두고
키비주얼은 **호버 시 커서를 따라오는 프리뷰**로만 노출한다. 타이포가 먼저 읽히고,
이미지는 확인용으로 뒤따른다. 모바일에서는 호버가 없으므로 인라인 썸네일로 자동 전환.

**Contact 를 거대 텍스트 한 줄로:** 폼을 넣지 않았다. 이 규모의 스튜디오에서
문의 폼은 응답 지연만 만든다. 메일 직결이 빠르다.

## 3. 히어로 영상

`http://www.lasagna.kr/background.mp4` 를 **이 세션에서 받지 못했다** — 환경의 egress
허용목록에 `www.lasagna.kr` 이 없어 403(`host_not_allowed`)이 떨어진다. 프록시 설정
문제가 아니라 환경 네트워크 정책이다.

대신 **영상 없이도 완성돼 보이는 상태**로 만들어뒀다:

- `assets/video/background.mp4` 가 있으면 로드되고 페이드인
- 없으면 CSS 그라디언트 그라운드가 그대로 유지 (깨진 영역·검은 구멍 없음)
- 저채도는 **CSS 에서** 처리 — `saturate(0.12) contrast(1.14) brightness(0.46)`.
  소스를 그레이딩하지 않는다. 톤 조정은 `home.css` 한 줄.
- `prefers-reduced-motion` 이면 루프를 멈추고 한 프레임 고정

받는 방법: `site/assets/fetch-hero.sh` (다운로드 + 웹용 인코딩 + 포스터 추출까지).

## 4. 키비주얼

`~/Downloads/Lasagna Film/_yt_upload/` 는 디렉터 Mac 경로다. 이 세션은 클라우드
컨테이너라 접근 자체가 불가능하다(`~/Downloads` 없음).

`assets/kv/manifest.json` 이 **단일 소스**다. Work 섹션 전체가 이 파일에서 렌더링된다.
썸네일을 `kv-<id>.jpg` 로 떨어뜨리고 `placeholder` 를 `false` 로 바꾸면 끝 —
HTML/JS/CSS 는 건드릴 게 없다. 파일이 없으면 `_placeholder.svg` 로 폴백한다.

좌하단 주황 칩은 **아직 빈 슬롯**을 알려주는 개발용 표시다. 전부 채워지면 스스로 사라진다.

## 5. 남은 결정 (§10 과 별개로 v2 가 만든 것)

1. **Work 항목의 링크 대상** — 현재 `#work` 자리표시자. 케이스 상세 페이지를 만들지,
   외부 링크(유튜브·비핸스)로 보낼지 미정.
2. **BIOLIN 노출 수위** — 2026.08 런칭 전이고 네이밍이 상표 클리어런스 전이다.
   현재는 프로젝트명만 노출하고 비주얼·네이밍 후보는 넣지 않았다. 런칭 전까지 이 선을 유지 권장.
3. **DAREFIT 카피** — 의료광고 심의 대상. 현재 "압구정 다리핏의원" 사실 표기만 있고
   치료·효과 표현은 없다. 케이스 상세를 만들 때 의료법 §56 재검토 필요.
4. **영문/국문 비율** — 지금은 헤드라인 국문 + 라벨 영문. 일본 유통(아라타·리보)을 고려하면
   `/en` 분기가 필요할 수 있으나 v2 범위 밖으로 뒀다.
